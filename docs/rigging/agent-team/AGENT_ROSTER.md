# Agent Roster

The repository has no executable custom-agent configuration. These durable charters and the orchestration protocol are the supported team definition. When multi-agent execution exists, roles may run separately; otherwise one agent must preserve role-separated conclusions before synthesis.

| Agent | Bounded responsibility | Charter |
| --- | --- | --- |
| Rig Program Director | Scope, arbitration, decision log, synthesis, sequencing | [01](charters/01_RIG_PROGRAM_DIRECTOR.md) |
| Repository and Reference Analyst | Evidence-linked inventory and artifact status | [02](charters/02_REPOSITORY_REFERENCE_ANALYST.md) |
| Canonical Rig Schema Architect | Shared identities, hierarchy, contracts, extension points | [03](charters/03_CANONICAL_RIG_SCHEMA_ARCHITECT.md) |
| Anatomy and Proportion Specialist | Landmarks, profile parameters, boundary distinctions | [04](charters/04_ANATOMY_PROPORTION_SPECIALIST.md) |
| Kinematics and Control Engineer | Transforms, articulation, limits, manipulation, invalid states | [05](charters/05_KINEMATICS_CONTROL_ENGINEER.md) |
| Orientation and Pose-State Architect | Regional view vocabulary, compatibility, fallback | [06](charters/06_ORIENTATION_POSE_STATE_ARCHITECT.md) |
| Garment Interface Architect | Semantic garment pieces, fitting, seams, state | [07](charters/07_GARMENT_INTERFACE_ARCHITECT.md) |
| Layering, Masking, and Occlusion Engineer | Dynamic render relations and non-destructive coverage | [08](charters/08_LAYERING_MASKING_OCCLUSION_ENGINEER.md) |
| Interaction Anchor and Serialization Engineer | Anchors, relationships, versioned transfer | [09](charters/09_INTERACTION_SERIALIZATION_ENGINEER.md) |
| Rig Implementation Integrator | Source-fit, migration boundaries, prototype sequencing | [10](charters/10_RIG_IMPLEMENTATION_INTEGRATOR.md) |
| Rig QA and Combinatorial Auditor | Independent challenge and designed acceptance gate | [11](charters/11_RIG_QA_COMBINATORIAL_AUDITOR.md) |
